# Analisis Data E-Commerce Olist Brasil (2016-2018)

## 1. Deskripsi Proyek
Proyek ini merupakan analisis data operasional end-to-end untuk perusahaan e-commerce Olist di Brasil. Tujuan utama dari analisis ini yaitu menemukan akar permasalahan dari penurunan kepuasan pelanggan dan menyusun strategi perbaikan logistik berbasis data.

## 2. Struktur Direktori
Susunan fail dan folder dalam repositori ini adalah sebagai berikut.
A. data merupakan folder tempat menyimpan berkas mentah dan berkas bersih hasil pemrosesan.
B. notebooks yaitu wadah khusus untuk menyimpan fail eksplorasi data berektensi .ipynb.
C. sql ialah lokasi penyimpanan fail kueri ekstraksi data berektensi .sql.
D. dashboards adalah tempat menyimpan fail Power BI Desktop beserta gambar tangkapan layar visualisasinya.
E. README.md merupakan halaman dokumentasi utama proyek ini.

## 3. Alat dan Teknologi
Teknologi yang digunakan dalam pengerjaan proyek ini meliputi beberapa perangkat berikut.
A. Python Pandas dan NumPy untuk pembersihan serta manipulasi data mentah.
B. Google BigQuery SQL untuk segmentasi dan ekstraksi data berskala besar.
C. Power BI Desktop untuk pembuatan dasbor visualisasi bisnis interaktif.

## 4. Latar Belakang Masalah
Perusahaan menghadapi kendala serius berupa anjloknya rating ulasan pelanggan dari 4.2 menjadi 2.2 bintang. Analisis ini berfokus pada data transaksi dan logistik guna menemukan penyebab pasti dari memburuknya pengalaman berbelanja pelanggan tersebut.

## 5. Temuan Utama
A. Keterlambatan pengiriman logistik merupakan faktor paling dominan yang merusak rating pelanggan.
B. Pelanggan yang berdomisili di wilayah geografis pelosok seperti Roraima dan Amapa mengalami durasi pengiriman yang sangat lambat.
C. Terdapat jeda pemrosesan pesanan yang terlalu lama dari pihak penjual sebelum barang diserahkan kepada kurir pengiriman.

## 6. Rekomendasi Strategis
A. Mengoptimalkan rute logistik dan menjalin kerja sama dengan pusat distribusi lokal khusus untuk wilayah utara Brasil.
B. Memberlakukan sistem penalti atau batas waktu otomatis bagi penjual yang memproses pesanan terlalu lama.
C. Meningkatkan transparansi sistem pelacakan logistik sehingga pelanggan bisa memantau pergerakan barang secara akurat tanpa harus mengajukan komplain.
